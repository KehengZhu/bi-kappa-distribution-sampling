Choosing a sampler

All five samplers are used the same way: construct, call define(...), then call operator() once per sample.

Each owns a seedable std::mt19937, and each accepts your own engine instead.

Positions from your own spatial density general_position_generator g.define(dim, lower, upper, rho)

bi_kappa_distribution and bi_maxwellian_distribution transform standard random variates directly. The other three use rejection sampling against an envelope estimated in define(...); see Rejection-sampler settings: probe_points, max_reject_tries.

With the default cap, bi_kappa_distribution samples the bi-Kappa distribution conditioned on a box of 20 thermal speeds per component. For kappa <= 3/2 this removes an appreciable part of the tail. Pass no_cap() to sample the bi-Kappa distribution itself; see The velocity cap.

Units

The samplers do not fix units. Velocities are returned in the units of theta_perp, theta_par or sqrt(w), and positions in the units of the bounds. No mass enters: for a distribution written in energy, use w = |v|^2 = 2E/m.
