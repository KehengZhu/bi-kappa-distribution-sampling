Detailed Description

template<typename RealType = double>
class field_aligned_velocity_generator< RealType >

Samples field-aligned velocities: an arbitrary parallel speed-squared distribution along B, with a Maxwellian perpendicular spread.

The parallel component is w_par = v_par^2, drawn from a user-defined distribution g(w_par); the parallel speed is |v_par| = sqrt(w_par) and its direction is set by a fixed sign (+1 along B, -1 opposite B). (For a distribution originally posed in energy, w_par = v_par^2 = 2E_par/m, so the mass drops out.) The two perpendicular components are independent Gaussians with N(0, theta_perp^2/2), i.e. a Maxwellian with thermal speed theta_perp (same convention as bi_maxwellian_distribution). The result is returned in the global (lab) frame.

auto gW = [](double w){ return std::exp(-0.5 * w); }; // any positive g(w), w = v_par^2
field_aligned_velocity_generator<double> gen;
gen.define(gW, 0.0, 40.0, 1.0, {0, 0, 1}, +1); // g, v2_min, v2_max,
// theta_perp, B, sign
gen.seed(12345);
auto v = gen(); // {vx, vy, vz}
