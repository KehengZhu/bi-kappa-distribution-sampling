Usage examples

Short examples for the five samplers.

They use Real = double; float also works. Every sampler is used the same way: construct, call define(...), then call operator() once per sample.

Building the tests and the demo

The headers need only a C++11 compiler. To build and run the code in cpp/:

make -C cpp test # regression suite; exit status 0 if every check passes
cd cpp && make && ./main.exe # short worked examples of all five samplers
make -C cpp CXX=clang++ test # use a different compiler

Bi-Kappa velocities

#include "bi_kappa_distribution.H"
#include <fstream>
using Real = double;
using BK = bi_kappa_distribution<Real>;
BK biKappa;
// kappa theta_perp theta_par ub cap seed
biKappa.define(2.0, 1.0, 2.0, {0, 0, 1}, BK::no_cap(), 20030410);
std::ofstream out("samples_bikappa.txt");
for (int i = 0; i < 100000; ++i) {
BK::point_type v = biKappa(); // {vx, vy, vz} in the global frame
out << v[0] << ' ' << v[1] << ' ' << v[2] << '\n';
}

The seed is the sixth argument, so the cap has to be given when a seed is passed to define(...). Alternatively, call biKappa.seed(20030410) after define(...).

The velocity cap

The fifth argument, max_normalized_velocity, is a cap in thermal speeds. It defaults to 20, the value used in release 1.0.0.

BK dist;
dist.define(2.0, 1.0, 2.0, {0, 0, 1}); // cap = 20 (default)
dist.define(2.0, 1.0, 2.0, {0, 0, 1}, BK::no_cap()); // no cap
dist.define(2.0, 1.0, 2.0, {0, 0, 1}, 50.0); // cap = 50
bool c = dist.param().capped(); // true for a finite cap
dist.max_normalized_velocity(BK::no_cap()); // remove the cap
dist.max_normalized_velocity(0.0); // throws std::invalid_argument

With a finite cap, a draw is redrawn if |v_i| / theta_i > cap for any component in field-aligned coordinates. The samples then follow the bi-Kappa distribution conditioned on that box, not the bi-Kappa distribution itself. For kappa <= 3/2 a cap of 20 removes an appreciable part of the high-energy tail; the paper's section on finite velocity bounds quantifies this. Use no_cap() when the tail matters.

The box is aligned with the field-aligned axes and rotates with ub. Global-frame components are bounded individually only when ub = {0, 0, 1}; the speed is always bounded by cap * sqrt(2 theta_perp^2 + theta_par^2). See The velocity cap for details.

Bi-Maxwellian velocities

The same interface without kappa. The cap works as for bi_kappa_distribution, with the same default of 20; for a Maxwellian it has no practical effect.

#include "bi_maxwellian_distribution.H"
using BM = bi_maxwellian_distribution<double>;
BM biMaxwell;
biMaxwell.define(1.0, 2.0, {0, 0, 1}); // theta_perp, theta_par, ub
biMaxwell.define(1.0, 2.0, {0, 0, 1}, BM::no_cap(), 20030410); // no cap, with a seed
BM::point_type v = biMaxwell();

Seeding

BK dist;
dist.define(2.0, 1.0, 2.0);
dist.seed(55555); // s >= 0: the same seed gives the same sequence
dist.seed(-1); // s < 0: seed from std::random_device

Without a seed, runs are not reproducible. On every sampler seed(s) also calls reset(), which discards any variate cached from earlier draws, so reseeding restarts the stream exactly. For bi_kappa_distribution a given seed gives the same values under libc++ and libstdc++ on the same architecture; the values are not bitwise identical across architectures, and they differ from release 1.0.0. bi_maxwellian_distribution uses std::normal_distribution, whose values depend on the standard library, and gives the same values as release 1.0.0.

Sharing one engine

Pass your own engine to operator() to draw several samplers from one stream. For bi_kappa_distribution the engine must produce a power-of-two number of distinct values, as std::mt19937 and std::mt19937_64 do.

#include <random>
std::mt19937 gen(42u);
BK core, halo;
core.define(5.0, 1.0, 1.0);
halo.define(2.0, 3.0, 3.0);
BK::point_type a = core(gen); // both draw from gen
BK::point_type b = halo(gen);

Changing parameters

define(...) replaces the whole configuration. Each single-parameter setter re-validates the full set.

BK dist;
dist.define(2.0, 1.0, 1.0);
dist.kappa(5.0);
dist.theta_par(2.5);
dist.ub({1, 2, 3});
dist.max_normalized_velocity(BK::no_cap());

Overflow near kappa = 1/2

Close to kappa = 1/2, some bi-Kappa draws exceed the largest representable floating-point number. Without a cap they are returned with infinite components; with a cap they are redrawn. n_nonfinite() counts such draws and n_attempts() counts all attempts since the last define(), seed() or reset().

BK dist;
dist.define(0.505, 1.0, 1.0, {0, 0, 1}, BK::no_cap());
for (int i = 0; i < 1000000; ++i) {
BK::point_type v = dist();
if (!std::isfinite(v[0]) || !std::isfinite(v[1]) || !std::isfinite(v[2])) {
// handle or discard the draw
}
}
unsigned long long lost = dist.n_nonfinite();

Under -ffast-math the compiler may assume that no infinity occurs, so no_cap() and the counters are unreliable. bi_kappa_distribution.H then prints a compile-time note; define BI_KAPPA_ALLOW_FAST_MATH to silence it. See Finite precision near kappa = 1/2 for typical rates.

Isotropic velocities from your own density

general_velocity_generator draws w = |v|^2 from a density g(w) you supply, by rejection sampling, and gives the velocity an isotropic direction with speed sqrt(w). There is no mass argument: for a distribution written in energy, use w = 2E/m.

#include "general_velocity_generator.H"
#include <cmath>
using Real = double;
// Maxwellian with thermal speed 1, written as a density in w = |v|^2.
auto gW = [](Real w) -> Real { return std::sqrt(w) * std::exp(-w); };
general_velocity_generator<Real> velGen;
// g w_min w_max
velGen.define(gW, 0.0, 40.0);
velGen.seed(20030410);
general_velocity_generator<Real>::point_type v = velGen();

Field-aligned velocities

field_aligned_velocity_generator draws w = v_par^2 from your density g(w) and puts the parallel component along ub (sign = +1) or opposite to it (sign = -1). The two perpendicular components are Maxwellian with thermal speed theta_perp, each N(0, theta_perp^2 / 2), and each is capped at 20 * theta_perp by default. The result is returned in the global frame.

#include "field_aligned_velocity_generator.H"
#include <cmath>
using Real = double;
using FA = field_aligned_velocity_generator<Real>;
auto gW = [](Real w) -> Real { return std::exp(-0.5 * w); }; // density in w = v_par^2
FA faGen;
// g w_min w_max theta_perp ub sign
faGen.define(gW, 0.0, 40.0, 1.0, {0, 0, 1}, +1);
faGen.seed(20030410);
FA::point_type v = faGen();
// Without the perpendicular cap:
faGen.define(gW, 0.0, 40.0, 1.0, {0, 0, 1}, +1, 1024, 100000, FA::no_cap());

Positions from your own density

general_position_generator draws positions in one to three dimensions from a density rho(x) in an axis-aligned box, by rejection sampling. The point is a std::vector<Real> of length dimension.

#include "general_position_generator.H"
#include <cmath>
using Real = double;
using pos_t = general_position_generator<Real>::point_type; // std::vector<Real>
auto rho = [](const pos_t& x) -> Real { return 1.0 + std::sin(x[0]) * std::sin(x[1]); };
general_position_generator<Real> posGen;
const Real pi = 3.14159265358979;
// dim lower upper density
posGen.define(2, {-pi, -pi}, {pi, pi}, rho);
posGen.seed(20030410);
pos_t x = posGen();

Errors

  • define(...) and the setters throw std::invalid_argument for a value outside its valid range (see Parameter reference).
  • The general, field-aligned and position generators throw std::runtime_error if called before define(...), if max_reject_tries is exhausted, or if your function returns a negative or non-finite value.
  • bi_kappa_distribution and bi_maxwellian_distribution throw std::runtime_error after 10^6 consecutive rejections by the cap.
try {
general_velocity_generator<Real> g;
general_velocity_generator<Real>::point_type v = g(); // not defined yet: throws
} catch (const std::runtime_error& e) {
// handle the error
}

Demo program

cpp/main.cpp runs a short example of each sampler:

#include <random>
#include <cmath>
#include <iostream>
#include <fstream>
typedef double Real;
// Local headers
#include "bi_kappa_distribution.H"
#include "bi_maxwellian_distribution.H"
#include "general_position_generator.H"
#include "general_velocity_generator.H"
#include "field_aligned_velocity_generator.H"
int main()
{
const Real kappa = 2.0;
const Real theta_perp = 1.0;
const Real theta_par = 2.0;
// Short worked examples of the five samplers; each writes its samples to a text file
// (vx vy vz per line) that python/visualize_samples.ipynb plots. The regression suite
// is separate: `make test`.
const int n_particle = 50000;
std::cout << "=== Example 1: BiKappaDistribution ===" << std::endl;
// no_cap(): these samples follow the bi-Kappa distribution itself. Omitting the fifth
// argument applies the default cap of 20 thermal speeds (as in release 1.0.0), which
// samples the bi-Kappa distribution conditioned on that component-wise box.
bi_kappa_distribution<Real> biKappa;
biKappa.define(kappa, theta_perp, theta_par, {0,0,1},
bi_kappa_distribution<Real>::no_cap(), 20030410);
{
std::ofstream out("samples_bikappa.txt");
for (int i = 0; i < n_particle; ++i) {
const bi_kappa_distribution<Real>::point_type v = biKappa();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_bikappa.txt" << std::endl;
}
std::cout << "\n=== Example 2: BiMaxwellianDistribution ===" << std::endl;
// no_cap(), as above; the default is again a cap of 20 thermal speeds.
bi_maxwellian_distribution<Real> biMaxwell;
biMaxwell.define(theta_perp, theta_par, {0,0,1},
bi_maxwellian_distribution<Real>::no_cap(), 20030410);
{
std::ofstream out("samples_bimaxwellian.txt");
for (int i = 0; i < n_particle; ++i) {
const bi_maxwellian_distribution<Real>::point_type v = biMaxwell();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_bimaxwellian.txt" << std::endl;
}
std::cout << "\n=== Example 3: general_velocity_generator (isotropic Maxwellian via w=|v|^2) ==="
<< std::endl;
// g(w) = sqrt(w) * exp(-w/theta^2) with w = |v|^2 is the speed-squared density
// of an isotropic Maxwellian of thermal speed theta: with dw = 2|v| d|v| it maps
// to the Maxwell speed pdf ~ |v|^2 exp(-|v|^2/theta^2), i.e. each Cartesian
// component is N(0, theta^2/2). theta = theta_perp = 1 here, and w_max = 25
// truncates at |v| = 5 theta.
const Real theta_iso = theta_perp;
auto speedSqPdf = [theta_iso](Real w) -> Real {
return std::sqrt(w) * std::exp(-w / (theta_iso * theta_iso));
};
general_velocity_generator<Real> velocityGen;
velocityGen.define(speedSqPdf,
static_cast<Real>(0.0),
static_cast<Real>(25.0));
velocityGen.seed(20030410);
{
std::ofstream out("samples_general_velocity.txt");
for (int i = 0; i < n_particle; ++i) {
const general_velocity_generator<Real>::point_type v = velocityGen();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_general_velocity.txt"
<< std::endl;
}
std::cout << "\n=== Example 4: general_position_generator (rho=1+sin(x)sin(y)) ===" << std::endl;
typedef general_position_generator<Real>::point_type position_point_type;
auto rho = [](const position_point_type &x) -> Real {
return 1 + std::sin(x[0]) * std::sin(x[1]);
};
static double pi = 3.14159;
general_position_generator<Real> positionGen;
positionGen.define(2, {-pi, -pi}, {pi, pi}, rho);
positionGen.seed(20030410);
{
std::ofstream out("samples_general_position.txt");
for (int i = 0; i < n_particle; ++i) {
const position_point_type x = positionGen();
out << x[0] << " " << x[1] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_general_position.txt"
<< std::endl;
}
std::cout << "\n=== Example 5: field_aligned_velocity_generator (uniform w_par, B=(1,1,1)) ==="
<< std::endl;
// The simplest possible input: g(w_par) = 1 makes w_par = v_par^2 uniform on
// [0, w_max], and the Jacobian dw = 2 v_par d(v_par) turns that into the linear
// ramp p(v_par) = 2 v_par / w_max on [0, sqrt(w_max)]. A density that is flat in
// w is a straight line in v_par -- the clearest illustration of what the change
// of variables does. The perpendicular plane is Maxwellian with thermal speed
// theta_perp, and B is tilted off the axes so the rotation is exercised.
const Real w_max_par = 4.0; // v_par spans [0, 2]
auto parallelSpeedSqPdf = [](Real) -> Real { return Real(1.0); };
field_aligned_velocity_generator<Real> fieldAlignedGen;
fieldAlignedGen.define(parallelSpeedSqPdf,
static_cast<Real>(0.0),
w_max_par,
theta_perp,
{1, 1, 1},
+1);
fieldAlignedGen.seed(20030410);
{
std::ofstream out("samples_field_aligned.txt");
for (int i = 0; i < n_particle; ++i) {
const field_aligned_velocity_generator<Real>::point_type v = fieldAlignedGen();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_field_aligned.txt"
<< std::endl;
}
return 0;
}
