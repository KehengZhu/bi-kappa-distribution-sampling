Detailed Description

template<typename RealType = double>
class general_velocity_generator< RealType >

Samples velocities from a user-defined speed-squared distribution g(w).

The sampled value is w = |V|^2, so the speed is |V| = sqrt(w) and the direction is isotropic in 3D. (For a distribution originally posed in energy, w = |V|^2 = 2E/m, so the mass drops out of this generator entirely.)

auto gW = [](double w){ return std::exp(-0.5 * w); }; // any positive g(w), w = |v|^2
general_velocity_generator<double> gen;
gen.define(gW, 0.0, 40.0); // g, v2_min, v2_max
gen.seed(12345);
auto v = gen();
