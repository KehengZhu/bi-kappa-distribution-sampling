Detailed Description

template<typename RealType = double>
class bi_maxwellian_distribution< RealType >

Bi-Maxwellian distribution for 3D velocity sampling.

Components are independent Gaussians with anisotropic thermal widths: Vx ~ N(0, theta_perp^2/2), Vy ~ N(0, theta_perp^2/2), Vz ~ N(0, theta_par^2/2).
