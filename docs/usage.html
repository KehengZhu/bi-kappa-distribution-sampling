Usage Examples

Practical, copy-pasteable recipes for the five samplers.

Every snippet uses Real = double; substitute float or your project's Real as needed. All generators follow the same lifecycle: construct → define(...) → call.

Building and running the demo

The bundled driver runs the test suite and writes 100k samples from each generator to samples_*.txt:

cd cpp
make
./main.exe

Bi-kappa velocity samples

Sample a 3D bi-kappa velocity distribution, anisotropic about the field direction ub, and stream the samples to a file.

#include "bi_kappa_distribution.H"
#include <fstream>
using Real = double;
bi_kappa_distribution<Real> biKappa;
// kappa theta_perp theta_par ub cap seed
biKappa.define(2.0, 1.0, 2.0, {0, 0, 1}, 100.0, 20030410);
std::ofstream out("samples_bikappa.txt");
for (int i = 0; i < 100000; ++i) {
bi_kappa_distribution<Real>::point_type v = biKappa(); // {vx, vy, vz}, global frame
out << v[0] << ' ' << v[1] << ' ' << v[2] << '\n';
}

Reproducible runs (seeding)

Each sampler owns an internal std::mt19937. Seed it for byte-for-byte reproducible sequences; re-seeding with the same value restarts the stream.

bi_kappa_distribution<Real> dist;
// (a) seed as the last define() argument (bi_kappa only):
dist.define(2.0, 1.0, 2.0, {0, 0, 1}, 20.0, /*seed*/ 55555);
// (b) or seed any time after define() (all samplers):
dist.define(2.0, 1.0, 2.0);
dist.seed(55555); // same seed -> identical sequence
dist.seed(-1); // negative -> unpredictable seed from std::random_device

Sharing one RNG across samplers

Pass your own std::mt19937 to operator() when several samplers should draw from a single stream (e.g. for coordinated reproducibility).

#include <random>
std::mt19937 gen(42u);
bi_kappa_distribution<Real> perp, par;
perp.define(2.0, 1.0, 1.0);
par.define (2.0, 1.0, 5.0);
auto vp = perp(gen); // both consume the same gen
auto vq = par (gen);

Reconfiguring a sampler

Reconfigure everything with define(...), or change one parameter at a time with the convenience setters — each setter re-validates the full parameter set.

bi_kappa_distribution<Real> dist;
dist.define(2.0, 1.0, 1.0); // initial configuration
dist.kappa(5.0); // change one field...
dist.theta_par(2.5); // ...each rebuilds + re-validates
dist.ub({1, 2, 3});
dist.define(3.0, 1.5, 2.5, {0, 0, 1}, 20.0); // or replace the whole config at once

Custom speed-squared distribution

general_velocity_generator draws a speed from any speed-squared PDF g(w) you supply (by rejection sampling, with w = |V|²) and assigns an isotropic 3D direction, so |V| = sqrt(w). There is no mass parameter: for a distribution originally posed in energy, w = |V|² = 2E/m, so the mass drops out.

#include "general_velocity_generator.H"
#include <cmath>
using Real = double;
auto gW = [](Real w) -> Real { return std::exp(-0.5 * w); }; // any positive g(w), w = |v|^2
general_velocity_generator<Real> velGen;
// g v2_min v2_max
velGen.define(gW, 0.0, 40.0);
velGen.seed(20030410);
general_velocity_generator<Real>::point_type v = velGen();

Field-aligned velocity (anisotropic)

field_aligned_velocity_generator builds an anisotropic velocity about the field direction ub: the parallel component draws v_par² from your speed-squared PDF g(w) (so |v_par| = sqrt(w)), pointing along ub for sign = +1 or opposite it for sign = -1, while the two perpendicular components are a Maxwellian with thermal speed theta_perp (each ~ N(0, theta_perp²/2), the same convention as bi_maxwellian_distribution). The result is returned in the global frame.

#include "field_aligned_velocity_generator.H"
#include <cmath>
using Real = double;
auto gW = [](Real w) -> Real { return std::exp(-0.5 * w); }; // any positive g(w), w = v_par^2
field_aligned_velocity_generator<Real> faGen;
// g v2_min v2_max theta_perp ub sign
faGen.define(gW, 0.0, 40.0, 1.0, {0, 0, 1}, +1);
faGen.seed(20030410);
field_aligned_velocity_generator<Real>::point_type v = faGen(); // {vx, vy, vz}, global frame

Custom spatial density

general_position_generator draws positions in 1D/2D/3D from any density rho(x) by rejection sampling in an axis-aligned box. The returned point is a std::vector<Real> of length dimension.

#include "general_position_generator.H"
#include <cmath>
using Real = double;
using pos_t = general_position_generator<Real>::point_type; // std::vector<Real>
auto rho = [](const pos_t& x) -> Real { return 1.0 + std::sin(x[0]) * std::sin(x[1]); };
general_position_generator<Real> posGen;
const Real pi = 3.14159265358979;
// dim lower upper density
posGen.define(2, {-pi, -pi}, {pi, pi}, rho);
posGen.seed(20030410);
pos_t x = posGen(); // length-2 vector

Error handling

  • The general and field-aligned velocity generators throw std::runtime_error if called before define(...).
  • define(...) throws std::invalid_argument on bad input (e.g. kappa <= 0.5, non-positive theta/cap, v2_min >= v2_max, v2_min < 0, a zero ub, sign other than ±1, dimension outside 1–3).
  • Velocity samplers throw std::runtime_error if the cap rejection loop fails 10⁶ times in a row.
try {
general_velocity_generator<Real> g;
auto v = g(); // not define()d yet -> throws
} catch (const std::runtime_error& e) {
// handle "must be define(...)d before sampling"
}

Complete worked example

The full driver below configures all four generators and writes their samples. See test_suite.H for further patterns (reproducible seeding, cap enforcement, and redefinition).

#include <random>
#include <cmath>
#include <iostream>
#include <fstream>
typedef double Real;
// Local headers
#include "bi_kappa_distribution.H"
#include "bi_maxwellian_distribution.H"
#include "general_position_generator.H"
#include "general_velocity_generator.H"
#include "field_aligned_velocity_generator.H"
#include "test_suite.H"
int main()
{
const Real kappa = 2.0;
const Real theta_perp = 1.0;
const Real theta_par = 2.0;
const int n_particle = 100000;
if (run_all_tests() != 0)
{
return 1;
}
std::cout << std::endl;
std::cout << "=== Example 1: BiKappaDistribution ===" << std::endl;
bi_kappa_distribution<Real> biKappa;
biKappa.define(kappa, theta_perp, theta_par, {0,0,1}, 100.0, 20030410);
{
std::ofstream out("samples_bikappa.txt");
for (int i = 0; i < n_particle; ++i) {
const bi_kappa_distribution<Real>::point_type v = biKappa();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_bikappa.txt" << std::endl;
}
std::cout << "\n=== Example 2: BiMaxwellianDistribution ===" << std::endl;
bi_maxwellian_distribution<Real> biMaxwell;
biMaxwell.define(theta_perp, theta_par, {0,0,1}, 20.0, 20030410);
{
std::ofstream out("samples_bimaxwellian.txt");
for (int i = 0; i < n_particle; ++i) {
const bi_maxwellian_distribution<Real>::point_type v = biMaxwell();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_bimaxwellian.txt" << std::endl;
}
std::cout << "\n=== Example 3: general_velocity_generator (g(w)=exp(-w/2), w=|v|^2) ==="
<< std::endl;
auto speedSqPdf = [](Real w) -> Real { return std::exp(-Real(0.5) * w); };
general_velocity_generator<Real> velocityGen;
velocityGen.define(speedSqPdf,
static_cast<Real>(0.0),
static_cast<Real>(40.0));
velocityGen.seed(20030410);
{
std::ofstream out("samples_general_velocity.txt");
for (int i = 0; i < n_particle; ++i) {
const general_velocity_generator<Real>::point_type v = velocityGen();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_general_velocity.txt"
<< std::endl;
}
std::cout << "\n=== Example 4: general_position_generator (rho=1+sin(x)sin(y)) ===" << std::endl;
typedef general_position_generator<Real>::point_type position_point_type;
auto rho = [](const position_point_type &x) -> Real {
return 1 + std::sin(x[0]) * std::sin(x[1]);
};
static double pi = 3.14159;
general_position_generator<Real> positionGen;
positionGen.define(2, {-pi, -pi}, {pi, pi}, rho);
positionGen.seed(20030410);
{
std::ofstream out("samples_general_position.txt");
for (int i = 0; i < n_particle; ++i) {
const position_point_type x = positionGen();
out << x[0] << " " << x[1] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_general_position.txt"
<< std::endl;
}
std::cout << "\n=== Example 5: field_aligned_velocity_generator (g(w)=exp(-w/2), B=z, +) ==="
<< std::endl;
auto parallelSpeedSqPdf = [](Real w) -> Real { return std::exp(-Real(0.5) * w); };
field_aligned_velocity_generator<Real> fieldAlignedGen;
fieldAlignedGen.define(parallelSpeedSqPdf,
static_cast<Real>(0.0),
static_cast<Real>(40.0),
theta_perp,
{0, 0, 1},
+1);
fieldAlignedGen.seed(20030410);
{
std::ofstream out("samples_field_aligned.txt");
for (int i = 0; i < n_particle; ++i) {
const field_aligned_velocity_generator<Real>::point_type v = fieldAlignedGen();
out << v[0] << " " << v[1] << " " << v[2] << "\n";
}
std::cout << "wrote " << n_particle << " samples to samples_field_aligned.txt"
<< std::endl;
}
return 0;
}
